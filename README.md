### How I build

Everything here was built with Claude Code and Codex working like a small team: one agent plans
and writes a spec, subagents write the code, and the two tools review each other. I approve the plan
before any code gets written, read every diff, and nothing ships until the tests pass. Payments and
security code I write or check line by line myself.
